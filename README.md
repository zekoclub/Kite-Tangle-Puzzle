# Kite Tangle Puzzle

A Basant kite puzzle game for Android, made in Unity 2D.

Free each kite whose string lies **on top** of the tangle, send it to the rooftop (chhat) of its color, and don't let the waiting slots fill up. Bo Kata!

- Unity **6000.0.84f1**, portrait, Android (IL2CPP, ARM64)
- Scene: `Assets/Scenes/Game.unity` (you can rebuild it from the menu **Kite Tangle → Build Game Scene**)
- Levels are generated from a seed, and each one is checked to be solvable and to need real thinking

See [CLAUDE.md](CLAUDE.md) for the full rules, the code architecture, the UI hooks, build commands and the roadmap.
